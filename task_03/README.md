# Задание 3 — масштабирование и координаты под курсором

Отдельный проект на **Qt C++ / QOpenGLWidget**, продолжение `task_02`. Для сборки достаточно того же комплекта Qt и MinGW, что используется во втором задании: в частности, **Qt 5.5.1 / MinGW 4.9.2 (32-bit)**. QML и Qt Python не используются.

## Возможности

- Вращение Земли перетаскиванием мыши с зажатой левой кнопкой.
- Приближение и удаление колёсиком мыши; расстояние камеры ограничено, чтобы камера не оказалась внутри сферы.
- Определение пересечения визирного луча с единичной сферой с учётом перспективной проекции, текущих углов вращения и расстояния до камеры.
- Широта и долгота под курсором с шестью знаками после запятой, целочисленный FPS в `QStatusBar`. Если курсор вне диска Земли, вместо координат отображаются прочерки.
- Сфера отображается через VBO/IBO и GLSL 1.20. Выбор наиболее крупной подходящей `Map_*.tif(f)` по `GL_MAX_TEXTURE_SIZE`, фильтрация `GL_NEAREST`, как в задании 2.

## Как открыть в Qt Creator

Откройте **`task_03/CMakeLists.txt`** как отдельный проект. Выберите **тот же Kit, что и для задания 2**: `Desktop Qt 5.5.1 MinGW 4.9.2 32-bit`. Не используйте Qt 5.15 / MSVC из прежних инструкций.

После обновления из Git удалите старую папку сборки именно третьего задания или выполните в Qt Creator очистку конфигурации CMake, чтобы она не сохранила старый выбор Qt/компилятора. Сам исходный каталог `task_03` удалять не нужно.

**CMake Warning про CodeBlocks Extra Generators — предупреждение, а не ошибка.** Ранее конфигурация прерывалась из-за моего необоснованного требования `Qt5 5.15`; теперь `CMakeLists.txt` повторяет конфигурацию второго задания и не требует конкретной минорной версии Qt.

## Сборка вручную на Windows (cmd.exe)

Если ваш Qt установлен в `C:\Qt\Qt5.5.1`, выполните из корня репозитория:

```bat
cd /d C:\Projects\FotonXD
set "PATH=C:\Qt\Qt5.5.1\Tools\mingw492_32\bin;C:\Qt\Qt5.5.1\5.5\mingw492_32\bin;%PATH%"
cmake -S task_03 -B build\task_03 -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/Qt5.5.1/5.5/mingw492_32"
cmake --build build\task_03
build\task_03\Shilin_3d_task_3.exe
```

Перед конфигурацией удалите старый `build\task_03`, если он был создан с другим генератором, компилятором или Qt. При запуске вне Qt Creator добавьте каталог Qt `bin` в `PATH` (в примере выше уже добавлен).

## Карты

Скопируйте `Map_*.tif` или `Map_*.tiff` в `task_03/maps/`. Можно оставить изображения в `task_02/maps/` — программа просматривает и этот каталог. Также можно указать первым аргументом путь к каталогу или конкретной карте. Для чтения TIFF нужен соответствующий плагин изображений Qt, как и во втором задании. Без карты шар отображается одноцветным, а вращение, масштабирование и координаты продолжают работать.

## Проверка в окне приложения

Перемещайте мышь над Землёй — внизу отобразятся FPS и координаты. Поверните Землю с зажатой ЛКМ, затем измените масштаб колёсиком. При уходе курсора на фон координаты заменяются прочерками. Координаты рассчитываются для сферической модели Земли без учёта геодезического эллипсоида.
