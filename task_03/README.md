# Задание 3 — масштабирование и геодезические координаты под курсором

Отдельный проект на **Qt 5.15 / C++ / QOpenGLWidget**. Продолжает задание 2, не меняя его исходников. QML и Python не используются.

## Реализовано

- Вращение сферы Земли левой кнопкой мыши.
- Масштабирование колёсиком мыши: расстояние камеры от центра ограничено диапазоном 1.15–20 радиусов Земли, чтобы не проходить сквозь сферу.
- Визирный луч для курсора строится с помощью обратной матрицы перспективной проекции, после чего обратной матрицей model-view переводится в локальные координаты вращающейся сферы.
- Вычисляется ближайшее положительное пересечение луча с единичной сферой, широта — `asin(y)`, долгота — `atan2(x,z)`; результат зависит от текущих углов поворота.
- `QStatusBar`: целочисленный FPS, широта и долгота с 6 знаками после запятой, сведения о карте. Если курсор не над диском Земли, координаты скрываются.
- Рисование сферы индексированной сеткой (VBO/IBO и GLSL 1.20), выбор самой большой подходящей `Map_*.tif(f)` с учётом `GL_MAX_TEXTURE_SIZE` и фильтрация `GL_NEAREST`, как во второй работе.

## Карты

Поместите `Map_*.tif` / `Map_*.tiff` в `task_03/maps/`. Чтобы не дублировать большие файлы, проект также просматривает `task_02/maps/`. Можно передать первым аргументом программы путь к каталогу карт или к конкретному файлу:

```powershell
Shilin_3d_task_3 "D:/maps"
```

TIFF читается через `QImageReader`: установленная сборка Qt должна содержать плагин чтения TIFF (Qt Image Formats). Без карты шар всё равно отрисовывается одноцветным, а расчёт координат остаётся доступен.

## Сборка

CMake 3.16+, Qt 5.15 с модулями Widgets/OpenGL, компилятор C++11. Например, для Windows и Qt 5.15.2:

```powershell
cmake -S task_03 -B build/task_03 -DCMAKE_PREFIX_PATH="C:/Qt/5.15.2/msvc2019_64"
cmake --build build/task_03 --config Release
```

Корневой CMakeLists.txt от задания 1 удалён, поэтому собирать нужно из `task_03/` (или `task_02/` для второй работы).

## Проверка

1. Удерживая ЛКМ, поворачивайте Землю: геокоординаты под курсором меняются вместе с поворотом.
2. Прокрутите колесо: диаметр Земли на экране меняется, координаты сразу пересчитываются с новой моделью камеры.
3. На сфере статус имеет вид `FPS: 120 | Lat: 12.345678, Lon: -34.567890 | Map: ...`; над фоном — `Lat: --, Lon: --`.
4. При пустом каталоге карт геометрия и определение координат всё равно работают.

Сферическая модель предполагает нулевую высоту и не использует геодезический эллипсоид.


## Проверка сборки и геометрии

В проекте есть консольный тест `GeoPickingTest` (8 проверок пересечения, поворотов,
масштабирования и выхода за пределы сферы). Для Windows после установки Qt 5.15:

```powershell
cmake -S task_03 -B build/task_03 -DCMAKE_PREFIX_PATH="C:/Qt/5.15.2/msvc2019_64" -DBUILD_TESTING=ON
cmake --build build/task_03 --config Release
ctest --test-dir build/task_03 -C Release --output-on-failure
```

Запускаемый файл для сборки Visual Studio: `build/task_03/Release/Shilin_3d_task_3.exe`.
При запуске вне Qt Creator проверьте, что Qt `bin` доступен в `PATH` либо
запустите `windeployqt` для собранного exe; чтение TIFF дополнительно требует
плагина Qt Image Formats. В GitHub Actions конфигурация, сборка и тесты запускаются
на Linux и Windows при каждом push в `main`.
