# FotonXD

Учебные проекты стажировки в «Фотон».

Каждое новое задание оформляется как самостоятельный проект, чтобы его можно было отдельно открыть, собрать и показать на проверке.

## Структура

```text
FotonXD/
├── CMakeLists.txt        # Задание 1 (существующий проект, оставлен без переноса)
├── CubeWidget.*          # Задание 1
├── MainWindow.*          # Задание 1
├── main.cpp              # Задание 1
└── task_02/              # Задание 2 — отдельный проект
```

Начиная со второго задания используем каталоги `task_XX/`. Это позволяет не ломать уже сданные/проверяемые проекты при выполнении следующих заданий.

## Задания

### Задание 1 — минимальный пример и FPS

Вариант: **QOpenGLWidget**. Текущие исходники задания находятся в корне репозитория.

### Задание 2 — текстурированная Земля

Находится в [`task_02/`](task_02/).

Реализованы сфера на VBO/IBO + GLSL, вращение мышью, измерение FPS, чтение `Map_*.tif(f)` через `libtiff`, автоматический выбор максимально подходящей текстуры по `GL_MAX_TEXTURE_SIZE` и фильтрация `GL_NEAREST`.

Инструкции по сборке и размещению TIFF-файлов: [`task_02/README.md`](task_02/README.md).
