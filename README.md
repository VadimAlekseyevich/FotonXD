# FotonXD

Учебные задания по 3D-графике и картографической обработке изображений. Этот README — единое место для договорённостей по оформлению репозитория и следующим работам. Полное условие всех шести заданий находится в [задание.md](задание.md); оно имеет приоритет в вопросах функциональных требований.

## Общие требования к дальнейшим заданиям

- **Язык и интерфейс:** только Qt + C++; не использовать QML, Qt Python или другие реализации вместо Qt C++.
- **Вариант графики:** `QOpenGLWidget`. Продолжать подход из уже работающего второго задания (OpenGL, VBO/IBO, GLSL), если новое условие не требует иного.
- **Среда пользователя:** Windows, **Qt 5.5.1**, **MinGW 4.9.2 (32-bit)** (`C:/Qt/Qt5.5.1/5.5/mingw492_32` и `C:/Qt/Qt5.5.1/Tools/mingw492_32`). Не выставлять минимальную версию Qt 5.15 и не навязывать MSVC/новый компилятор. Использовать API, реально доступные в Qt 5.5.1 и C++11.
- **CMake и сборка:** ориентироваться на структуру и настройки `task_02/CMakeLists.txt`: `cmake_minimum_required(VERSION 3.10)`, `CMAKE_CXX_STANDARD 11`, `CMAKE_AUTOMOC ON`, `find_package(Qt5 COMPONENTS Widgets OpenGL REQUIRED)`. Каждое задание должно открываться и собираться отдельно в Qt Creator тем же Kit, что второе.
- **Без непрошеных дополнений:** не добавлять тестовые проекты, CTest, GitHub Actions/CI, дополнительные фреймворки и усложнения без прямой просьбы. Сначала обеспечить сборку и работу самого задания на указанной конфигурации; не выдавать успешную сборку на другой версии Qt за подтверждение совместимости с Qt 5.5.1. Если сборка в целевом окружении не запускалась — прямо сообщать об этом.
- **Не ломать готовые задания:** изменения в новой работе делать в её собственной папке; не переписывать исходники предыдущих заданий без отдельного запроса. По возможности переиспользовать подход и настройки предыдущего задания.

## Организация репозитория и документация

- В корне: `задание.md`, **этот единственный `README.md`**, `.gitignore` и папки работ. Исходники задания 1 из корня были удалены по просьбе пользователя; они доступны в истории Git.
- Отдельный каталог на каждую работу: `task_02/`, `task_03/`, далее `task_04/`, `task_05/`, `task_06/`. Внутри — необходимые C++-файлы, заголовки, `CMakeLists.txt` и ресурсы.
- **Не создавать README.md внутри проектов и подпапок** (включая `maps/`). Все инструкции по сборке, запуску и особенности работ размещать здесь, в корневом README.
- Большие локальные карты `Map_*.tif` / `Map_*.tiff` не коммитить; хранить в `task_XX/maps/` либо передавать приложению путь к картам. Пустые каталоги карт в Git поддерживать с помощью `.gitkeep`, а не вложенных README.
- Не удалять и не менять пользовательские данные, не относящиеся к конкретному запросу. После правок давать точный коммит и инструкции для реальной среды пользователя.

## Сборка проекта на имеющейся конфигурации Windows

В Qt Creator открывать **`task_XX/CMakeLists.txt`**, а не корень репозитория; выбирать **Desktop Qt 5.5.1 MinGW 4.9.2 32-bit**. При переходе на другую конфигурацию Qt/компилятора сначала очищать *каталог сборки* (не исходники).

Пример из `cmd.exe` для третьего задания (из `C:\Projects\FotonXD`):

```bat
set "PATH=C:\Qt\Qt5.5.1\Tools\mingw492_32\bin;C:\Qt\Qt5.5.1\5.5\mingw492_32\bin;%PATH%"
cmake -S task_03 -B build/task_03 -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/Qt5.5.1/5.5/mingw492_32"
cmake --build build/task_03
build\task_03\Shilin_3d_task_3.exe
```

Старый CMake-кэш от другой версии Qt/генератора необходимо удалить перед конфигурацией. Предупреждение CMake о deprecated CodeBlocks Extra Generator само по себе не является ошибкой. Для загрузки TIFF необходим установленный плагин чтения TIFF в данной сборке Qt.
