# Задание 2 — наложение текстуры на модель Земли

Отдельный проект на Qt 5.15 / C++ для варианта **QOpenGLWidget**.

## Что реализовано

- вращение шара мышью (левая кнопка + перемещение);
- приближение и отдаление камеры колесом мыши или клавишами `Ctrl + +` / `Ctrl + -` с ограничением безопасной дистанции;
- сфера строится один раз как индексированная треугольная сетка и отрисовывается через VBO/IBO и GLSL 1.20;
- загрузка TIFF через `libtiff`;
- автоматический запрос `GL_MAX_TEXTURE_SIZE`;
- поиск файлов `Map_*.tif` и `Map_*.tiff` и выбор изображения с максимальным количеством пикселей, размеры которого не превышают ограничение OpenGL;
- наложение глобальной текстуры с координатами: слева направо `180 W -> 180 E`, сверху вниз `90 N -> 90 S`;
- фильтрация текстуры `GL_NEAREST`;
- FPS с целочисленной точностью в `QStatusBar`.

## Управление

- удерживайте левую кнопку мыши и перемещайте мышь, чтобы вращать Землю;
- прокручивайте колесо вверх или нажимайте `Ctrl + +` (`Ctrl + =` тоже поддерживается), чтобы приблизить планету;
- прокручивайте колесо вниз или нажимайте `Ctrl + -`, чтобы отдалить планету.

## Куда положить карты

Скопируйте локальные карты в каталог:

```text
task_02/maps/
```

Файлы карт намеренно не хранятся в Git.

Можно также передать каталог с картами первым аргументом программы:

```text
Shilin_3d_task_2 "D:/maps"
```

Или передать конкретный файл `Map_*.tif(f)`.

## Сборка

Требуются:

- Qt 5.15;
- CMake 3.16+;
- компилятор C++14;
- libtiff с CMake-пакетом `TIFF`.

Пример для Windows + Qt 5.15:

```powershell
cmake -S task_02 -B build/task_02 `
  -DCMAKE_PREFIX_PATH="C:/Qt/5.15.2/msvc2019_64"
cmake --build build/task_02 --config Release
```

Если `libtiff` установлен через vcpkg, дополнительно укажите toolchain:

```powershell
-DCMAKE_TOOLCHAIN_FILE="C:/vcpkg/scripts/buildsystems/vcpkg.cmake"
```

## Проверка задания

После запуска в строке состояния должно быть примерно:

```text
FPS: 240 | Map: Map_8192.tiff [8192x4096], GL max=16384
```

Числа зависят от видеокарты и ваших файлов. Землю можно вращать левой кнопкой мыши и приближать/отдалять колесом или сочетаниями `Ctrl + +` / `Ctrl + -`.
