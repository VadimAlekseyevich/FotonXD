# Локальные TIFF-карты

Положите сюда файлы вида:

```text
Map_*.tif
Map_*.tiff
```

При запуске приложение запросит `GL_MAX_TEXTURE_SIZE`, прочитает размеры найденных TIFF через `libtiff` и выберет карту с максимальным числом пикселей среди тех, у которых и ширина, и высота не превышают ограничение OpenGL.

Сами TIFF-файлы исключены из Git через корневой `.gitignore`.
