# Варианты заданий

1. Qt 3D: https://doc.qt.io/archives/qt-5.15/qt3d-index.html
2. QOpenGLWidget: https://doc.qt.io/archives/qt-5.15/qopenglwidget.html
3. QOpenGLWindow: https://doc.qt.io/archives/qt-5.15/qopenglwindow.html
4. QVulkanWindow: https://doc.qt.io/archives/qt-5.15/qvulkanwindow.html

**Примечание:** при создании проектов необходимо использовать только Qt C++ (запрещено использовать Qt QML и Qt Python).

## Задание 1. Минимальный пример и FPS.

1. Создать GUI-приложение, состоящее из главного окна, которое содержит 2 компонента:
   - а) Область вывода графики в соответствии с вариантом задания.
   - б) QStatusBar.
2. Реализовать минимальный пример 3D-графики, реализующий вращение объекта-куба мышкой, с использованием компонента графики, определённого вариантом.
3. Научится определять частоту обновления кадров (FPS) области вывода графики и выводить её в QStatusBar с целочисленной точностью.

## Задание 2. Наложение текстуры.

1. Реализовать в качестве вращающегося объекта шар (в случае возможности реализации объекта несколькими способами, необходимо выбрать способ, обеспечивающий самый высокий FPS; для OpenGL, скорее всего, таким способом будут являться шейдеры). Данный шар будет являться моделью Земли.
2. Определить размеры текстурного буфера и наложить на шар текстуру Map_*.tiff максимального подходящего размера из представленных с интерполяцией по ближайшему соседу.

Текстура представляет собой изображение, покрывающее всю поверхность Земли, пиксели которого имеют одинаковый размер в градусах. Т. е. угловые точки изображения имеют следующие координаты: левый-верхний угол – 90° N 180° W, правый-верхний – 90° N 180° E, левый-нижний – 90° S 180° W, правый-нижний – 90° S 180° E.

## Задание 3. Масштабирование и определение геодезических координат под курсором.

1. Реализовать функцию масштабирования шара Земля (приближение, удаление) вращением колёсика мыши.
2. Реализовать функцию определения геодезических координат точки под курсором:
   - а) Провести визирный луч от экрана к шару в соответствии с использованной моделью камеры и вычислить почку пересечения этого луча с шаром.
   - б) Зная текущие углы поворота шара, получить геодезические координаты точки пересечения луча с шаром.
3. Вычисленные геодезические координаты выводить в QStatusBar с точностью 6 знаков после запятой вместе с FPS.

## Задание 4. Картографические проекции.

1. Изучить 2 проекции: универсальную поперечную проекцию Меркатора (UTM) и полярную стереографическую проекцию (UPS) (разделы 3.2.3 и 3.3.1.2 «Geomatics Guidance Note 7-2»).
2. Найти все параметры соответствующей проекции в файлах изображения, необходимые для соотнесения пиксельных и геодезических координат.
3. Создать консольное приложение, работающее следующем образом:
   - а) Приложение принимает на вход изображение GeoTIFF в одной из указанных проекций и массив пиксельных и геодезических координат из соответствующих файлов точек (формат файла точек – на усмотрение студента).
   - б) Приложение для открытого изображения реализует функции геопривязки planar2geo(x,y,lat,lon) и geo2planar(x,y,lat,lon), выполняющие пересчёт пиксельных координат (x,y) в геодезические (lat,lon) и обратно.
   - в) Приложение сравнивает точки с данными геопривязки:
     1. Вычисляет геодезические координаты (lat1,lon1) по пиксельным функцией planar2geo.
     2. Вычисляет пиксельные координаты (x1,y1) по геодезическим (lat1,lon1).
     3. Сравнивает (x1,y1) и (lat1,lon1) с данными из файла точек.
     4. Выводит в консоль: 2 пары анализируемых пиксельных точек и 2 пары анализируемых геодезических точек с точностью минимум 6 знаков после запятой, а также разницу соответствующих пиксельных и геодезических координат.

В libgeotiff/libgdal уже реализованы некоторые функции для работы с planar2geo/geo2planar – можно использовать их.

Если студент владеет только libtiff, он может реализовать самостоятельно формулы для проекций из «Geomatics Guidance Note 7-2» или изучить libgeotiff или libgdal и использовать формулы из этих библиотек.

4. Правильно реализованные функции planar2geo/geo2planar должны выдавать на тестовых картинках результаты соответствующие списку точек (с точностью минимум 5 знаков после запятой).

## Задание 5. Контрастирование изображений.

1. Изучить (теоретически) способы наложения текстур на объекты для соответствующего варианта заданий (понадобится в следующем задании).
2. Реализовать функцию открытия маршрутов GeoTIFF, выполняющую следующие операции:
   - а) Чтение растра и фоновой яркости (тег GDAL_NO_DATA).
   - б) Вычисление вычисление параметров контрастирования методом обрезания по 2% краёв гистограммы, не учитывая фоновую яркость.
   - в) Контрастирование растра в 8-битное изображение в соответствии с параметрами контрастирования.
3. Добавить в консольное приложение предыдущего задания следующий функционал: при открытии изображения выполняется его контрастирование (рекомендуется выводит в консоль прогресс, т. к. это может быть долгая процедура) и сохранение полученного 8-битного изображения в файл TIFF (или GeoTIFF).

## Задание 6. Наложение геопривязанных изображений (маршрутов).

1. Внедрить в приложение заданий 1-3 функции открытия маршрута GeoTIFF и пиксельно-геодезических преобразований координат из заданий 4 и 5.
2. Реализовать функцию наложения контрастированного растра маршрута на шар Земли поверх текстуры из Задания 2, работающую одним из следующих способов (на выбор студента; разрешается использовать интерполяцию по ближайшему соседу):
   - а) Способ 1 (шейдеры): с помощью шейдеров определять, какие пиксели маршрута и текстуры видны на экране и отображать их.
   - б) Способ 2 (триангуляционная сеть): разбить растр на треугольники; поверх шара Земли создать объекты-плоскости этих треугольников, на которые наложить маршрут.
   - в) Способ 3 (только для Qt 3D): использовать функции Qt 3D для текстурирования.
3. Добавить в главное окно панель меню в одним пунктом «Открыть изображение». По нажатию на пункт меню выполняется:
   - а) Выбор открываемого маршрута GeoTIFF с диска.
   - б) Открытие маршрута (задания 4 и 5).
   - в) Наложение маршрута поверх текстуры (см. п. 2).
   - г) Вывод в заголовок главного окна имени открытого маршрута.
   - д) Вывод в QStatusBar, вместе с FPS и координатами под курсором, координат центральной точки открытого маршрута с точностью минимум 6 знаков после запятой.

Если в приложении уже открыт маршрут – его данные необходимо удалить перед открытием нового маршрута.
